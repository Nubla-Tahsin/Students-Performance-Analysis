# Student Performance Analysis Project

## **1. Problem Statement**
Analyzing student academic performance manually can be time-consuming and difficult. This project focuses on evaluating students' subject-wise marks, total marks, percentages, grades, pass/fail status, and attendance to identify academic strengths and areas that need improvement.

## **2. Objectives**
- Analyze students' marks in five subjects: Maths, English, Science, Computer, and Social Science.
- Calculate total marks and percentage.
- Identify students' pass/fail status based on subject marks.
- Assign grades according to students' percentages.
- Calculate class average, highest marks, and lowest marks.
- Identify students with attendance below 75%.
- Compare Class 9 and Class 10, and Section A and Section B.
- Create a dashboard to visualize student performance.

## **3. Tools and Technologies**
- **Microsoft Excel** – Data analysis and management.
- **Excel Formulas** – Calculate total marks and percentages.
- **IF and AND Functions** – Determine pass/fail status.
- **AVERAGE, MAX, MIN** – Statistical analysis.
- **COUNTIF and AVERAGEIF** – Count and compare student performance.
- **Conditional Formatting** – Highlight low marks and attendance.
- **Excel Charts** – Visualize academic performance.
- **PivotTables** – Summarize and compare student data.
- **Excel Dashboard** – Present key performance indicators.

## **4. Conclusion**
The Student Performance Analysis project demonstrates how Microsoft Excel can be used to analyze and visualize student academic data effectively. It helps identify top-performing students, students who need improvement, attendance issues, and class-wise performance. The dashboard provides meaningful insights that support better academic monitoring and decision-making.
